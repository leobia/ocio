# Acquisizioni della fonte versionate in Git

Per il corpus iniziale, conserviamo le acquisizioni della fonte come file immutabili nel repository, insieme a URL, data di acquisizione, vigenza e hash. Nuovi atti e redazioni vengono aggiunti manualmente; l'importazione legge i file locali e il database ne conserva una copia derivata per il modello canonico. Questa scelta rende il corpus riproducibile e verificabile senza dipendere dalla disponibilità delle fonti durante l'esecuzione; automatizzeremo gli aggiornamenti quando servirà.
